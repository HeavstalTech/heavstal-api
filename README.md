A zero-dependency multi-purpose SDK client for interacting with Heavstal Tech APIs. Supports ESM and CJS.

---

## Installation

Install via **npm**:
```bash
npm install @heavstal/api
```

Install via **yarn**:
```bash
yarn add @heavstal/api
```
